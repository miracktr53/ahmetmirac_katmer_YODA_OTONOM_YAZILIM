Takımlar Neden Git ve GitHub Kullanır?

Versiyon Kontrolüne Neden İhtiyaç Duyulur?

Normalde proje yaparken "son\_kutuphane", "en\_son\_kod", "gercek\_son" diye bir sürü dosya kaydediyoruz ve bir süre sonra hangisi doğruydu karışıyor. Bir yeri bozunca da eski çalışan haline dönmek çok zor oluyor. Git sayesinde her yaptığımız değişikliği kaydedebiliyoruz. Böylece kod çökerse veya bir hata yaparsak kolayca sorunsuz çalışan eski haline dönebiliyoruz.

Git ile GitHub Arasındaki Fark

Aslında Git bizim kendi bilgisayarımızda çalışan sistemin adı. Bütün değişiklikleri bilgisayarda tutuyor. GitHub ise bu Git dosyalarımızı internete yüklediğimiz ve diğer takım arkadaşlarıyla paylaştığımız platform.

Ekip Çalışmasına Katkıları

Takımca kod yazarken herkesin aynı anda aynı dosyada çalışması çok zor. Git sayesinde herkes kendi kısmını ayrı bir kolda yazabiliyor. Mesela ben kamera kısmını yazarken başka bir arkadaşım motor kısmını yazabiliyor. İşi biten kişi kodunu ana projeye eklemek için bir istek atıyor.

GitHub'ın Proje Yönetimi Özellikleri

GitHub sadece kodları depolamakla kalmıyor, projeyi yönetmemizi de sağlıyor. Oradaki kısımlarda takımdaki hataları veya yapılacak işleri listeleyebiliyoruz. Hatta işleri "yapılacak", "yapılıyor", "bitti" diye ayırabildiğimiz panoları var. Böylece takımda kimin neyle uğraştığı daha net belli oluyor.

Kulüp ve Takımlar İçin Önemi

Öğrenci takımlarında sürekli mezun olup ayrılanlar oluyor, yerlerine de yeni üyeler geliyor. Eğer eski kodlar sadece giden kişilerin kendi bilgisayarında kalırsa her seferinde her şeye sıfırdan başlamak gerekir. GitHub sayesinde eski üyelerin yazdığı kodlar ve neyi neden yaptıkları orada kalıyor. 

Otonom Araç Projesindeki Yeri

Otonom araç yaparken görüntü işleme, sensör okuma gibi bir sürü farklı birim var. Herkes Git sayesinde diğerlerinin kodunu bozmadan aynı anda kendi işini yapabiliyor. Ayrıca aracı piste çıkarıp test ederken, o an çalışan sorunsuz koda bir işaret koyabiliyoruz. Eğer piste yeni bir kod denerken araç bozulursa hemen o işaretlediğimiz çalışan eski koda dönüp teste devam edebiliyoruz.
